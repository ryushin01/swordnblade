# 디자인

## 참고

쇼핑몰은 [Half the Sky](https://halfthesky.app/)([CSS Design Awards](https://www.cssdesignawards.com/sites/half-the-sky/50250/))의 디자인 언어를 참고했습니다. 콘텐츠·이미지·코드는 가져오지 않았습니다.

- 석고색 바탕에 1px 선으로 나눈 정사각 칸
- 마우스를 올리거나 초점을 받으면 칸에 번지는 따뜻한 빛
- 상세: 왼쪽 큰 부조, 오른쪽 패널, 양옆에 선과 점을 둔 테라코타색 작은 제목, 타임라인
- Cormorant Garamond 스몰 캡스

한글은 웹 글꼴 대신 운영체제 명조체(맥 AppleMyungjo, 안드로이드 Noto Serif CJK, 윈도 바탕)를 씁니다. 한글 웹 글꼴은 모바일 첫 화면을 4~5초 늦췄습니다([개발 가이드](development.md#성능-lighthouse-모바일)). 한글은 낱말 중간에서 줄을 바꾸지 않습니다(`word-break: keep-all`).

참고 사이트의 보조 글자(약 2.6:1)는 명도 대비 기준에 못 미쳐 진하게 바꿨습니다.

어드민은 디자인 참고 없이 Ant Design 기본 테마를 쓰고, 명도 대비가 모자란 토큰만 바꿨습니다.

## 부조 일러스트 (`packages/sword-art`)

도검마다 이미지 파일 대신 `SwordArt` 매개변수(칼날 길이·너비·휘어짐·칼끝, 홈·능선·하몬·상감, 코등이·손잡이 감기·끝장식 종류와 색, 술)를 두고 SVG로 그립니다.

1. **높이 층**: 같은 모양을 회색으로 그립니다. 밝을수록 높습니다(능선·끈은 밝게, 홈은 어둡게).
2. **조명 필터**: 밝기를 알파로 바꾸고(`feColorMatrix luminanceToAlpha`) 흐린 뒤, 왼쪽 위에서 비추는 `feDiffuseLighting`·`feSpecularLighting`으로 석고 질감을 냅니다. 아래로 그림자를 떨어뜨립니다.
3. **채색 층**: 손잡이 끈·코등이·보석 같은 색을 `mix-blend-mode: multiply`로 얹어 칠한 부조처럼 보이게 합니다.

목록에서는 `frame="catalog"`로 모든 칼을 같은 축척으로 그려 와키자시와 쌍수도의 길이 차이가 보이게 하고, 상세에서는 `frame="fit"`으로 꽉 차게 그립니다. 어드민 상품 수정 화면에서 값을 바꾸면 미리보기가 바로 다시 그려집니다.

### 쌍수도

검은 옻칠 바탕에 붉은 견사 끈(`#a3241c`)을 마름모로 엇갈려 감고, 황동 코등이·칼집 고리·끝장식, 붉은 술을 달았습니다.
